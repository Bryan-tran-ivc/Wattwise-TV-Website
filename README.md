# Wattwise TV Energy Website

A concise data-visualisation project that helps users compare TV energy consumption more intelligently by looking at annual energy use (kWh/year) instead of relying only on star ratings.

## Overview

This project explores the question: can a larger, higher-star TV still use more electricity than a smaller, lower-star TV?

It presents an interactive website with:
- clear comparison charts
- size-vs-star analysis
- an appliance energy calculator
- brief narrative insights based on the supplied dataset

## Features

- Responsive website layout
- Interactive visual comparisons for TV size and energy rating
- Simple household energy calculator
- Evidence-based storytelling for product comparison

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Run locally


Open `index.html` directly in a browser


## Project goal

Help users make better purchasing decisions by comparing:
- TV size
- energy label stars
- annual electricity use

This makes the comparison more practical than looking at stars alone.

## Data note

The website uses the supplied TV registration dataset snapshot for analysis and visual storytelling. It focuses on correct interpretation of energy ratings and screen size differences.
